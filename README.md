## 🚀 Getting Started

### Prerequisites

- **Node.js** >= 18.0.0
- **npm** >= 9.0.0 (or yarn/pnpm)

### Installation

1. **Clone the repository**

   ```bash
   git clone https://github.com/yourusername/vault-password-frontend.git
   cd vault-password-frontend
   ```

2. **Install dependencies**

   ```bash
   npm install
   ```

3. **Start development server**

   ```bash
   npm run dev
   ```

4. **Open your browser**
   ```
   http://localhost:5173
   ```

### Build for Production

```bash
# Create optimized production build
npm run build

# Preview production build locally
npm run preview
```

### Desktop App (Electron)

The desktop build bundles the UI locally and sends API traffic through the Electron main process.

```bash
# Terminal 1: web dev server
npm run dev

# Terminal 2: Electron shell loading the dev server
npm run dev:desktop

# Packaged Windows installer
npm run build:desktop
```

Set `CRYPTA_API_BASE_URL` in the environment for development, or edit the fallback in `electron/config.cjs` before packaging for production. The installer is written to `release/`.

## 🎨 Customization

### Colors

Edit `tailwind.config.js` to customize the color scheme:

```js
theme: {
  extend: {
    colors: {
      primary: {
        500: '#0ea5e9',  // Your brand color
        // ... other shades
      },
    },
  },
}
```

### Animations

Custom animations are defined in `tailwind.config.js`:

```js
animation: {
  'float': 'float 3s ease-in-out infinite',
}
```

### Content

Update component files in `src/components/` to change text, links, and structure.
